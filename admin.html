Setup Required

Finish Supabase setup before using live admin data

The website can show demo data locally, but real production leads and documents need the Supabase project and Netlify function configured first.

  1. Open the Supabase project and run supabase/schema.sql in SQL Editor.
  2. Create the admin email and password in Supabase Authentication.
  3. Fill supabase-config.js with the project URL and anon key.
  4. Add SUPABASE_URL and SUPABASE_SERVICE_ROLE_KEY in Netlify environment variables.
  5. Deploy the site, then open /admin.html and sign in with the admin credentials.
Browser config needed in supabase-config.js 
window.YourEnergySupabaseConfig = {
  url: "https://YOUR_PROJECT_ID.supabase.co",
  anonKey: "YOUR_SUPABASE_ANON_KEY",
};
